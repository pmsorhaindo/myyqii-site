# MyyQii

Minimal one-page landing site for the artist brand **MyyQii** (canonical domain: `myyqii.com`).

## Contents

- `index.html` — page structure (name, one-liner, SoundCloud, contact)
- `styles.css` — dark, mobile-first layout

## Edit later

- **One-liner:** change the `.tagline` text in `index.html` (currently `Electronic music · Utrecht`)
- **Email:** update the `mailto:hello@myyqii.com` link and button label
- **SoundCloud:** profile is [soundcloud.com/myyqii](https://soundcloud.com/myyqii)

## Deploy

Static files at repo root — works with Vercel, Netlify, or GitHub Pages with no build step.

### Vercel (recommended)

1. Import `pmsorhaindo/myyqii-site` in Vercel
2. Framework preset: Other / static; root directory `.`
3. Point `myyqii.com` at the Vercel project (A / CNAME — see deploy notes once you have the `*.vercel.app` URL)
